NOISECAPTURE HTML

À propos de ce port Web

Un port HTML indépendant inspiré de NoiseCapture. Il s’exécute dans un navigateur : ce n’est pas l’application Android NoiseCapture.

01

Un port HTML indépendant

Cette interface Web est une adaptation indépendante de NoiseCapture, réalisée en HTML, CSS et JavaScript. Elle s’exécute dans un navigateur. Ce n’est ni l’application Android, ni un APK, et elle n’est pas présentée comme une version officielle.

02

Limites de mesure

Les valeurs sans calibration sont affichées sur une échelle relative 0–100, décalée depuis le niveau numérique du microphone. 0 correspond au seuil de silence numérique, pas au seuil d’audition. Le gain et la réponse fréquentielle varient selon les appareils : cette échelle ne représente pas des dB SPL réels.

Le réglage par sonomètre est indicatif : cette version Web n’applique pas de pondération fréquentielle A et ne fournit pas de mesure certifiée en dB(A).

03

Comment ça marche ?

Votre navigateur analyse localement le signal reçu par le microphone. Une valeur de niveau est calculée chaque seconde ; si vous l’autorisez, la position GPS est associée à ces relevés.

04

Respect de la vie privée

Aucun fichier audio n’est créé ni envoyé. Les mesures et les positions restent dans le stockage local de votre navigateur ; vous pouvez les exporter ou les supprimer depuis l’historique.

05

Conditions requises

Le microphone et la géolocalisation sont accessibles uniquement depuis une connexion sécurisée (HTTPS) ou depuis localhost. Votre navigateur demandera votre autorisation au démarrage d’une mesure.

06

Assistance de l’IA

La réalisation et la documentation de ce port HTML ont été effectuées avec l’assistance d’un outil d’intelligence artificielle. Ce projet indépendant n’est ni l’application Android d’origine ni une version officielle maintenue par ses auteurs.
